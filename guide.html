正在检测访问地址…

手机与电脑连接同一 Wi-Fi，扫码即可打开本页，获得 AI 讲解 + 语音导览。

服务需以 --host 0.0.0.0 启动（见下方部署三步）；二维码由服务实时生成，部署到任何服务器都会自动更新为对应地址。

部署三步

  1. 本机运行：py -m uvicorn main:app --host 0.0.0.0 --port 8000，浏览器打开 http://127.0.0.1:8000/guide
  2. 局域网（展厅 Wi-Fi）：手机直接扫码上方二维码即可访问
  3. 公网服务器：项目根目录已含 Dockerfile，执行 docker compose up -d --build 一键上线

讲解引擎：默认「知识库模板」；配置环境变量 LLM_BASE_URL / LLM_API_KEY / LLM_MODEL（任意 OpenAI 兼容大模型）后自动升级为「大模型润色」。语音使用微软神经语音（免密钥）。详见项目内《部署指南.md》。

数据接口 /api/v1 · 讲解 / 语音 / 二维码由本服务实时生成 · 数据来源：故宫博物院 · 陕西省地方志办公室 · 耀州窑考古研究 等公开资料
